## Часть 1. Основной документ.

### 1. Заголовок и базовая информация.

• **Название:** Painter

• **Назначение:** Проект № 12. Продукт.

• **Фаза проекта:** Phase II.

• **Технологический стек:** Java (библиотека Swing).

• **Статус проекта:** Полностью завершен.

### 2. Краткое описание проекта.

**Painter** – это десктопный графический редактор, созданный на языке Java с использованием библиотеки Swing.

Приложение позволяет пользователю рисовать на белом холсте с помощью различных инструментов: линии, эллипсы, прямоугольники, круги, квадраты, кисточка и ластик.

Редактор поддерживает выбор цвета (9 предустановленных + произвольный через JColorChooser), настройку толщины линии (от 1 до 20 пикселей), а также функции отмены (Undo) и повтора (Redo) действий.

Ключевыми особенностями являются: двуязычный интерфейс (русский/английский), сохранение и загрузка рисунков в текстовый файл, а также отображение координат курсора в заголовке окна.

Проект представляет собой полностью функциональный графический редактор с широким набором инструментов и продуманным пользовательским интерфейсом.

### 3. Четкие цели проекта.

• Создать работающий графический редактор с возможностью рисования базовых фигур.

• Реализовать 7 инструментов рисования: линия, эллипс, прямоугольник, круг, квадрат, кисточка, ластик.

• Реализовать систему выбора цвета (предустановленные + произвольный).

• Реализовать систему выбора толщины линии.

• Реализовать систему отмены/повтора действий (Undo/Redo) с использованием стеков.

• Реализовать сохранение и загрузку рисунков в текстовый файл.

• Реализовать двуязычный интерфейс (русский и английский).

• Реализовать удаление фигур с помощью ластика (по клику).

• Обеспечить корректную обработку событий мыши (нажатие, отпускание, перетаскивание).

• Продемонстрировать подход к разработке десктопных приложений на Java с использованием Swing и AWT.

### 4. Компоненты проекта.

Проект состоит из одного файла, содержащего несколько классов:

• **Main.java** – основной класс, наследующий JFrame. Содержит точку входа, меню, панель инструментов и внутренний класс MyPanel для рисования.

• **Класс Figure** – модель графической фигуры. Хранит тип, координаты, цвет, толщину и точки (для кисточки).

• **Класс DrawingState** – снимок состояния для системы Undo/Redo. Хранит массив фигур и их количество.

### 5. Инструкция по использованию.

- **5.1. Запуск:**

• Убедитесь, что установлен JDK (Java Development Kit) версии 8 или выше.

• Скомпилируйте и запустите Main.java (например, через IDE IntelliJ IDEA или из терминала: javac Main.java && java Main).

- **5.2. Цель приложения:**

• Создание простых растровых рисунков с помощью набора инструментов.

• Сохранение и загрузка рисунков для последующего редактирования.

- **5.3. Управление:**

• **Левая кнопка мыши (нажатие):** начало рисования фигуры или линии кисточкой.

• **Левая кнопка мыши (перетаскивание):** рисование фигуры или продолжение линии кисточкой.

• **Левая кнопка мыши (отпускание):** завершение рисования и фиксация фигуры.

• **Левая кнопка мыши (клик с ластиком):** удаление ближайшей фигуры.

• **Ctrl+Z:** отменить последнее действие (Undo).

• **Ctrl+Y:** вернуть отменённое действие (Redo).

• **Мышь:** управление меню и кнопками.

- **5.4. Интерфейс:**

• Главное окно размером 600x400 пикселей.

• Панель инструментов сверху с кнопками ◄ (Undo) и ► (Redo).

• **Меню:**

• Файл: Открыть, Сохранить, Выход.

• Инструмент: Прямая, Эллипс, Прямоугольник, Круг, Квадрат, Кисточка, Ластик.

• Цвет: Чёрный, Красный, Зелёный, Синий, Жёлтый, Оранжевый, Пурпурный, Голубой, Серый, Выбрать цвет.

• Толщина: 1, 2, 3, 4, 5, 8, 10, 15, 20 px.

• Язык: Русский, English.

• Справка: О программе.

• Заголовок окна отображает текущие координаты курсора (например, (150,200)).

- **5.5. Инструменты:**

• **Прямая** – рисует линию от точки нажатия до точки отпускания.

• **Эллипс** – рисует эллипс в прямоугольной области.

• **Прямоугольник** – рисует прямоугольник.

• **Круг** – рисует круг (диаметр = min(ширина, высота)).

• **Квадрат** – рисует квадрат (сторона = min(ширина, высота)).

• **Кисточка** – рисует свободные линии по траектории мыши.

• **Ластик** – удаляет ближайшую фигуру по клику (в радиусе 20 пикселей).

## Часть 2. Технический документ.

### 1. Цели разработки.

• Основной целью разработки было создание графического редактора на Java с использованием Swing для закрепления навыков работы с GUI, обработкой событий мыши и объектно-ориентированного программирования.

• Дополнительно проект направлен на изучение работы с меню, панелями инструментов, диалоговыми окнами (JColorChooser, JFileChooser), а также реализации системы Undo/Redo через стеки.

• Задачи включали: реализацию 7 инструментов рисования, работу с графикой через Graphics2D, сериализацию фигур в текстовый файл, поддержку двух языков и удаление фигур ластиком.

### 2. Использованные технологии.

• **Язык программирования:** Java

• **Графические библиотеки:** Swing, AWT.

• **Стандартные библиотеки:**

- java.util.ArrayList – для хранения списка точек кисточки.

- java.util.Stack – для стеков Undo/Redo.

- java.util.Scanner – для чтения файлов.

- java.io.PrintStream – для записи файлов.

- java.io.FileNotFoundException – для обработки ошибок ввода/вывода.

• **Модули Swing/AWT:**

- javax.swing.* – JFrame, JPanel, JMenu, JMenuItem, JButton, JColorChooser, JFileChooser, JOptionPane, JDialog.

- java.awt.* – Color, Graphics, Graphics2D, BasicStroke, Point, BorderLayout, FlowLayout, event.*.

### 3. Архитектура проекта.

• Проект реализован как десктопное приложение с разделением на три класса:

• Main – главное окно, меню и логика приложения.

• Figure – модель графической фигуры.

• DrawingState – снимок состояния для Undo/Redo.

• Основной поток: событийно-ориентированный (Event Dispatch Thread в Swing).

• Логика разделена по компонентам:

- Main – управление меню, инструментами, цветом, толщиной.

- MyPanel (внутренний класс) – отрисовка и обработка событий мыши.

- Figure – хранение и отрисовка фигуры.

- В каждом событии перерисовки выполняются: очистка фона, отрисовка временной фигуры, отрисовка всех сохраненных фигур.

### 4. Структура проекта.

• **Инициализация:** создание окна JFrame, панели рисования MyPanel, панели инструментов и меню.

• **Поля класса Main:**

- figures – массив фигур (до 1000).

- kFigures – текущее количество фигур.

- tool – текущий инструмент.

- currentColor, strokeWidth – текущий цвет и толщина.

- beginPoint, endPoint – координаты начала и конца фигуры.

- brushPoints – список точек для кисточки.

- undoStack, redoStack – стеки для Undo/Redo.

- isEnglish – флаг языка.

• **Методы Main:**

- createToolbar() – создание панели с кнопками Undo/Redo.

- createMenus() – создание всех меню и обработчиков.

- createMenuBar() – сборка строки меню.

- updateLanguage() – обновление текстов интерфейса.

- saveState() – сохранение состояния для Undo.

- undo(), redo() – отмена и повтор действий.

- restoreState(state) – восстановление состояния.

- updateButtons() – обновление доступности кнопок.

• **Класс MyPanel:**

- paint(g) – отрисовка фона, временной фигуры и всех сохраненных фигур.

- mousePressed, mouseReleased, mouseDragged, mouseClicked – обработка событий мыши.

• **Класс Figure:**

- Конструкторы для обычных фигур и кисточки.

- draw(g) – отрисовка фигуры.

- distanceTo(p) – расстояние от точки до фигуры.

- clone() – создание копии фигуры.

- toString() – сериализация в строку для сохранения.

• **Класс DrawingState:**

- Хранит массив фигур и количество.

### 5. Ключевые компоненты системы.

• **Холст (MyPanel):** Наследник JPanel, реализует MouseListener и MouseMotionListener. Отвечает за отрисовку и обработку мыши.

• **Фигуры (Figure):** Хранят тип, координаты, цвет, толщину. Для кисточки — список точек. Метод distanceTo() используется ластиком для поиска ближайшей фигуры.

• **Система Undo/Redo:** Реализована через два стека (undoStack, redoStack) класса Stack<DrawingState>. При каждом изменении сохраняется снимок состояния через saveState().

• **Система сохранения/загрузки:** Текстовый формат: первая строка — количество фигур, далее каждая фигура в отдельной строке. Кисточка сериализуется с полным списком точек.

• **Двуязычный интерфейс:** Реализован через флаг isEnglish и метод updateLanguage(), который обновляет тексты всех элементов меню и кнопок.

• **Ластик:** По клику находит ближайшую фигуру (distanceTo) в радиусе 20 пикселей и удаляет её из массива со сдвигом.

• **Горячие клавиши:** Реализованы через InputMap и ActionMap для Ctrl+Z (Undo) и Ctrl+Y (Redo).

### 6. Реализация пользовательского интерфейса.

• Интерфейс полностью реализован средствами Swing и AWT.

• Основные элементы: окно JFrame, панель рисования JPanel, строка меню JMenuBar, панель инструментов с кнопками, диалоги JColorChooser, JFileChooser, JOptionPane, JDialog.

• Отрисовка выполняется через Graphics и Graphics2D в методе paint().

• Используется BasicStroke для настройки толщины и стиля линий.

### 8. Основные сложности и способы их решения.

• **(1) Сложность:** корректная отрисовка временной фигуры при перетаскивании.

**Решение:** временная фигура создается в paint() на основе текущих beginPoint и endPoint, но не сохраняется в массив до отпускания мыши.

• **(2) Сложность:** реализация Undo/Redo без потери данных.

**Решение:** использование стеков Stack<DrawingState>, где каждый DrawingState содержит полную копию массива фигур (через clone()).

• **(3) Сложность:** поиск ближайшей фигуры для ластика.

**Решение:** метод distanceTo(p) в классе Figure, который вычисляет расстояние от точки до фигуры в зависимости от её типа (расстояние до отрезка, прямоугольника, эллипса или ломаной).

• **(4) Сложность:** сериализация кисточки (списка точек) в файл.

**Решение:** использование отдельного формата: сначала тип, цвет, толщина, затем количество точек и их координаты.

• **(5) Сложность:** обновление всех текстов при смене языка.

**Решение:** метод updateLanguage(), который обходит все компоненты меню через getMenuComponents() и обновляет их текст.

• **(6) Сложность:** обработка горячих клавиш в Swing.

**Решение:** использование InputMap и ActionMap через getRootPane().

### 9. Текущие ограничения проекта.

• Максимум 1000 фигур (ограничение массива).

• Отсутствует заливка фигур (только контур).

• Нет возможности перемещения уже нарисованных фигур.

• Нет выделения и группировки фигур.

• Нет экспорта в растровые форматы (PNG, JPEG).

• Код остается монолитным (все классы в одном файле).

• Отсутствует сохранение настроек между запусками.
